# Sprint Planning

## Sprint Goal

Надати користувачам можливість зареєструватися в системі та створити базовий профіль
(репетитора або учня), заклавши CI-процес для подальшої розробки.

## Definition of Done

- усі задачі спринту мають статус Done на дошці;
- код пройшов Code Review щонайменше одним іншим членом команди;
- усі автотести (юніт-тести) проходять успішно;
- немає відкритих критичних або блокуючих дефектів (мітка Bug із пріоритетом Critical/High);
- README.md оновлено відповідно до змін;
- код злито (merge) в основну гілку без конфліктів;
- функціонал перевірено вручну за критерієм прийнятності відповідної вимоги.
