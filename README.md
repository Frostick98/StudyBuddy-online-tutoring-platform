# StudyBuddy

Платформа для онлайн-репетиторства: поєднує учнів і репетиторів — від пошуку та
бронювання занять до онлайн-оплати й проведення уроків.

## Про проєкт

| Поле | Значення |
| --- | --- |
| Назва | StudyBuddy — платформа для онлайн-репетиторства |
| Призначення | Пошук репетитора, бронювання занять, онлайн-оплата, відеозв'язок/чат, відгуки та рейтинги |
| Тип системи | Web |
| Замовник | Освітній стартап StudyBuddy |
| Методологія | Scrum (6 спринтів по 2 тижні) |
| Автор | Висоцький Олександр |

**Статус:** ініціація проєкту (Sprint 0)

## Технології

- Git та GitHub — контроль версій і хостинг репозиторію;
- GitHub Projects — дошка задач (Kanban);
- C# / ASP.NET Core — планований стек розробки (ІІ семестр);
- Markdown — формат технічної документації.

## Як переглянути документацію проєкту

| Каталог | Що містить |
| --- | --- |
| docs/ | технічне завдання |
| docs/sdlc/ | вибір моделі SDLC, фази життєвого циклу, дорожня карта, DORA-рефлексія |
| docs/board/ | дошка задач, Sprint Plan, Definition of Done |
| docs/reports/ | звіти практичних занять у форматі docx |
