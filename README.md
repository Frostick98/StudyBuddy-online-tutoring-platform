# StudyBuddy

Платформа для онлайн-репетиторства: поєднує учнів і репетиторів - від пошуку та
бронювання занять до онлайн-оплати й проведення уроків. Призначена для учнів, які
шукають репетитора, і для репетиторів, які хочуть знаходити учнів та вести заняття онлайн.

## Можливості

Заплановано за дорожньою картою (6 спринтів по 2 тижні):

- реєстрація та вхід користувачів (email + пароль), профілі репетитора й учня;
- пошук репетиторів за предметом і ціною, календар доступності;
- бронювання занять та email-сповіщення про підтвердження;
- онлайн-оплата й історія платежів;
- відеозв'язок або чат під час заняття;
- відгуки та рейтинги репетиторів.

## Встановлення / запуск

Вихідний код з'явиться в каталозі `src/` у другому семестрі, тому запускати поки що нічого.
Щоб отримати робочу копію репозиторію з документацією:

```bash
git clone https://github.com/Frostick98/StudyBuddy-online-tutoring-platform.git
cd StudyBuddy-online-tutoring-platform
```

Для майбутньої розробки знадобиться .NET SDK (версію буде зафіксовано разом із першим кодом).

## Як зробити внесок

1. Створіть гілку від `main`: `git checkout -b feature/назва`.
2. Робіть невеликі коміти з повідомленнями у форматі `тип: що змінено` (наприклад, `docs: ...`, `chore: ...`).
3. Відкрийте pull request за шаблоном із `.github/` і дочекайтеся Code Review.

Дотримуйтесь Definition of Done з [Sprint Plan](docs/board/sprint-plan.md).
